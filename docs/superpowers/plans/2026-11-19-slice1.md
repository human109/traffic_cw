- Slice 0 Global Constraints 전부(KST `YYYY-MM-DDTHH:MM:SS+09:00`, naive는 ValueError, 결측≠0, 미래 정보 금지, 합성은 `tests/fixtures/`·테스트 안에서만, `.env` 금지, 네트워크 없는 테스트, 소유권)

## Review Focus

1. **보정값을 실제값처럼 쓰는 경우** — forward fill로 채운 bin(`imputed`)이 예측 입력으로는 `degraded`, 평가 레이블로는 제외되어야 한다. (Task 2 `test_imputed_flag`, Task 4 `test_backfill_skips_imputed`)
2. **보정이 미래 값을 쓰는 경우** — 결측 bin을 채울 때 그 뒤 bin의 값을 쓰면 안 된다. 결측 뒤 관측이 먼저 들어온 상태에서 다시 집계해도 결과가 같아야 한다. (Task 2 `test_ffill_uses_past_only`)
3. **같은 값이 반복되는 정상 데이터를 갱신 정지로 오판하는 경우** — 원본 시각이 바뀌지 않는 반복(no_update)은 갱신 정지가 아니다. 원본 시각이 6회 바뀌는 동안 값이 같을 때만 `frozen`. (Task 2 `test_frozen_requires_new_timestamps`)
4. **표본이 부족한 기준 모델이 숫자를 내는 경우** — 과거 동일 요일·시간대 평균은 3주 미만이면 `skipped`(NULL)여야 한다. (Task 4 `test_dow_mean_needs_three_weeks`)
5. **평가 기간에 공휴일·주말이 섞이는 경우** — 평가는 평일·비공휴일·대상 시각 07:00~09:00만. `calendar_info`가 비어 있으면 주말만 빼고 경고를 남긴다. (Task 4 `test_eval_excludes_weekend_and_holiday`)

### Task 2 (D-DAT-02b): 전처리 규칙 완성 — 소유: dev-data

**Files:** Modify `preprocessing/aggregate.py`, `preprocessing/README.md` · Create `preprocessing/rules.py`(판정 함수) · Test `tests/preprocessing/test_rules.py`, 기존 `test_aggregate.py` 갱신

**Consumes:** C-01 v1.2, settings(`partial_min_coverage`, `ffill_max_bins`, `frozen_repeat_count`)
**Produces:** `preprocessing.run` 시그니처 그대로. 규칙(순서대로):
1. **갱신 정지**: 링크별로 `source_timestamp`가 서로 다른 최근 관측을 시간순으로 볼 때, 같은 speed가 `frozen_repeat_count`회 이상 연속이면 그 6번째부터 집계에서 제외한다(lookback 창 앞쪽 관측도 판정에 쓰도록 창보다 `frozen_repeat_count×5분` 더 읽는다).
2. **본선 구간 속도**: 관측 본선 길이 합 / 전체 본선 길이 합 ≥ `partial_min_coverage`일 때만 산출(전부면 `ok`, 아니면 `partial`), 미만이면 `missing`. 길이 모름 규칙(`unweighted`)은 Slice 0 그대로.
3. **측도**: `is_mainline=0` 링크로 같은 방식(조화평균, 커버리지 기준 동일)으로 `speed_side` 산출. 측도가 없거나 기준 미달이면 NULL. 구간 `quality_flag`에는 영향 없음.
4. **짧은 결측 보정**: 본선 결과가 `missing`인 bin의 직전 연속 missing 개수(그 bin 포함)가 `ffill_max_bins` 이하이고, 그 앞 bin이 `missing`·`imputed`가 아닌 실제 값이면 그 값으로 채운다 → `quality_flag='imputed'`, `is_imputed=1`, `available_at`=bin 끝. 보정값을 다시 보정의 근거로 쓰지 않는다. 직전 bin은 DB에 이미 있는 값(이번 실행 이전)도 쓴다.
