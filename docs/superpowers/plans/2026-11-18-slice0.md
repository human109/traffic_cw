# Slice 0 (얇은 전체 흐름) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 이 프로젝트에서 서브에이전트는 `.opencode/agents/`의 프로젝트 에이전트(dev-*, reviewer)를 사용하고, 각 Task의 "소유" 에이전트에게 배정한다.

**Goal:** 수집 → DB → 5분 집계 → 현재 속도 유지 예측 → 대시보드를 최소 기능으로 끝까지 연결하고, 실제 API 키로 상시 수집을 시작한다.

**Architecture:** 모듈은 SQLite 테이블(C-01)과 C-06 진입점으로만 연결한다. 수집기는 수집원 어댑터 구조로 만들고, 첫 어댑터는 필드가 문서로 확인된 ITS(R-02)로 한다. 경찰청(R-01)은 응답 형식을 사람이 확인한 뒤 어댑터를 추가한다. 링크 매핑(R-03)이 확정되기 전에도 조회 범위 안의 링크 원본을 모두 저장해 두어, 매핑이 정해지면 과거 데이터부터 집계할 수 있게 한다.

**Tech Stack:** Python 3.14 (로컬 설치본, 3.11 이상 조건 충족), sqlite3(표준 라이브러리), requests, tenacity, lxml, pandas, numpy, APScheduler 3.x, streamlit, plotly, python-dotenv, pytest

**Spec:** `docs/superpowers/specs/2026-11-18-thin-slice-design.md`, `SPEC.md` v1.2, `AGENTS.md`, 리서치 `docs/research/R-01~R-04`

## Global Constraints

- AGENTS.md 6장 불변식 전부: 결측을 0으로 바꾸지 않음, 미래 정보 사용 금지, 합성 데이터는 `tests/fixtures/`에서만 쓰고 `synthetic` 표시, `.env` 읽기·출력 금지, 근거 없는 외부 사실은 `TODO(R-xx)`로 표시

- 경로 소유권은 AGENTS.md 2장을 따르고, 테이블 쓰기 소유권은 3장을 따른다.

- 실행 위치는 저장소 루트이고, pytest는 `pythonpath = ["."]`로 설정한다.
- 의존성 설치와 `requirements.txt` 수정은 orchestrator만 한다.
- 커밋은 orchestrator만 하며, 커밋 메시지 형식은 `[Task ID] 제목`이다.

## Review Focus

1. **응답은 성공인데 대상 링크 일부만 오는 경우** → `collection_log.status='partial'`로 기록하고, 오지 않은 링크의 레코드는 만들지 않는다. (Task 5 테스트 `test_partial_response_logs_partial`)
2. **같은 `createdDate`를 반복해서 받는 경우**(5분 갱신을 1분마다 조회) → 중복 행이 생기지 않고 `status='no_update'`, `record_count=0`이 된다. (Task 5 `test_repeat_fetch_no_update`)
3. **PC 절전 후 40분 만에 재개하는 경우** → 오래된 bin으로 예측하지 않는다. 최신 bin이 10분보다 오래되면 `input_quality='skipped'`, `predicted_value=NULL`이 된다. (Task 7 `test_stale_input_skipped`)
4. **API가 속도 0이나 음수, 빈 값을 주는 경우** → 0은 `default_value`, 음수는 `out_of_range`, 빈 값은 NULL로 처리하고 집계에서 뺀다. 구간 속도에 0이 섞이지 않는다. (Task 5 `test_speed_flags`, Task 6 `test_flagged_excluded`)
5. **tz가 없는 datetime이 진입점에 들어오는 경우** → 조용히 다른 시각으로 저장하지 않고 `ValueError`를 낸다. (Task 2 `test_naive_rejected`)
