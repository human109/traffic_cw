## 요약

- 엔드포인트는 `https://openapi.its.go.kr:9443/trafficInfo`이고, 쿼리 파라미터 `apiKey` 하나로 인증한다. 키는 **ITS 국가교통정보센터에 가입해서 따로 발급**받으며, 공공데이터포털 키로는 쓸 수 없다. 관리자 승인에 영업일 기준 3~5일이 걸린다. IP 인증 요건은 찾지 못했다.
- 응답은 XML(기본) 또는 JSON이다. 링크 단위 필드는 `linkId`, `startNodeId`, `endNodeId`, `speed`(km/h), `travelTime`(초), `createdDate`(YYYYMMDDHH24MISS), `roadName`, `roadDrcType`, `linkNo`이다. **교통량과 소통 상태 코드는 없다.**
- `type=all`일 때는 `minX/maxX/minY/maxY` 경위도 범위로 걸러서 조회할 수 있다. 공식 문서상 호출 제한은 "현재 없음"이다. 갱신 간격은 5분으로 보이지만 실측이 필요하다.
- **핵심 결론:** 공식 설명은 모두 이 API를 "고속도로 및 국도별 소통정보"라고 한다. 도로 유형 값도 `all/ex/its` 세 가지뿐이고, 돌발 API에 있는 `loc`(지방도)·`sgg`(시군도)가 없다. 그래서 **창원대로(지방도·시도) 링크는 들어 있지 않을 가능성이 높다** (추론, 확신도 중간). 반대 근거도 하나 있다. 고시의 응답 예시에 도시부 도로명("남문로")이 나온다. 결국 **실제 호출로만 판정할 수 있다.**
- 권고: ITS는 경찰청(R-01)의 대체 수집원이 아니라 **조건부 보조·교차검증 수집원**으로 둔다. 인증키를 발급받으면 창원 범위로 조회해 포함 여부부터 확인한다.

## 구현에 필요한 값

> 실호출 샘플을 받기 전까지 아래 값은 **고시 기준 초안**이다. 수집기 코드에서는 설정값으로 분리하고 `TODO(R-02)`를 표시한다.

**호출 형식**

```
GET https://openapi.its.go.kr:9443/trafficInfo
    ?apiKey={ITS_API_KEY}
    &type=all            # all | ex | its
    &drcType=all         # all | up | down | start | end
    &minX={경도min}&maxX={경도max}
    &minY={위도min}&maxY={위도max}
    &getType=xml         # xml(기본) | json
```

- 비밀정보 키 이름 제안: `ITS_API_KEY` (`.env.example`에 추가하도록 오케스트레이터에게 요청)
- 좌표는 WGS84 경위도(도 단위)로 추정한다. 고시 CCTV 예시가 `coordx=127.12`, `coordy=37.42`이기 때문이다.
- 창원대로를 감싸는 조회 범위(**추정치. R-03 좌표로 다시 확정**): `minX=128.55, maxX=128.80, minY=35.15, maxY=35.30`
- `getType=xml`을 권장한다. JSON은 키 대소문자와 envelope가 문서와 다를 수 있다(#4, #19). xml을 쓰면 SPEC 4.3의 원본 보관 경로 `data/raw/its/{YYYYMMDD}/{HHMMSS}.xml`과도 맞는다.

**응답 → C-02 매핑 초안**

| ITS 필드 (XML) | C-02 / SPEC 4.3 필드 | 변환 | 비고 |
|---|---|---|---|
| `linkId` | `link_id` | 문자열 그대로 | 10자리 표준링크 ID (예시 1750000100) |
| `speed` | `speed` | float, km/h | 결측 표현 미확인 → 빈 값이면 NULL. 0은 결측인지 정지인지 판정 보류 |
| `travelTime` | `travel_time` | float, 초 | 소수 제공(예 12.01) |
| `createdDate` | `source_timestamp` | `YYYYMMDDHHMMSS` → KST ISO8601 (`common/` 헬퍼 사용) | 시간대 표기가 없어 KST로 추정(추론) |
| (없음) | `volume` | NULL | 제공하지 않음 |
| (없음) | `congestion_code` | NULL | 제공하지 않음. 속도로 등급을 계산하면 파생값으로 구분 |
| 상수 `"its"` | `source` | – | |
| `roadName`, `roadDrcType`, `startNodeId`, `endNodeId` | (C-02에 없음) | 원본 파일에만 남김 | 링크 매칭 검증용 |
| `resultCode` | `collection_log` 상태 판정 | `0` = 성공 | 오류 코드 목록 미확인 |

## 미확인·사람 확인 필요

1. **[사람] 인증키 신청**: www.its.go.kr에 회원가입하고 오픈데이터 → 교통소통정보 인증키를 신청한다. 목적에는 "개인 학습용 교통 예측 연구"를 적는다. 승인에 영업일 3~5일이 걸린다. 키는 `.env`에만 보관한다.
2. **[사람] 창원대로 포함 여부 실호출 확인 (가장 중요)**. 키를 받으면 아래처럼 호출하고, 키를 지운 응답을 `docs/research/samples/its_trafficInfo_changwon_*.xml`로 저장해 달라.
   - (a) `type=all&drcType=all&minX=128.55&maxX=128.80&minY=35.15&maxY=35.30&getType=xml`
   - (b) 같은 범위에 `type=its`
   - 판정: `roadName`에 "창원대로" 또는 1020호선 구간이 있는지 확인하고, R-03에서 확정한 창원대로 링크 ID가 응답에 있는지 대조한다. `totalCount`도 기록한다.
3. **[사람] 갱신 주기 실측**: 같은 요청을 1분 간격으로 30분간 보내 `createdDate`가 바뀌는 간격을 기록한다(#16).
4. **[사람] 결측 표현**: 위 샘플에서 speed/travelTime이 빈 값, 0, 음수인 사례가 있는지 확인한다(#18).
5. **[사람] JSON 형태**: `getType=json` 응답 1건을 저장해 실제 envelope와 키 대소문자를 확인한다(#19).
6. **[사람] 오류 응답 형식**: 키를 일부러 틀리게 넣은 요청 1건의 응답 본문을 저장한다. `auth_error` 판정 규칙(SPEC 4.5)에 쓴다.
7. **[리서치] IP 인증 여부**: 공식 문구를 찾지 못했다(#20). 키 신청 화면에 IP 입력란이 있는지 신청할 때 봐 달라.
8. **[리서치] 2023년 개정 고시(제2023-20호)**가 교통소통정보 절을 바꿨는지 확인이 필요하다(#1). 본문을 받지 못했다.
9. **[R-03 연계]** 창원대로 각 구간의 표준노드링크 도로등급과 노선번호(국도 중용 여부)를 확인한다(#9).
10. its.go.kr 접속 불가(#14)가 일시적인 장애인지 확인한다. 사람이 브라우저로 접속해 보면 된다.
