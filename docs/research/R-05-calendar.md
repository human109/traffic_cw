# R-05 공휴일·대체공휴일 데이터원과 경남 학사일정(방학)·산단 휴가 확보 방법

| 항목 | 내용 |
|---|---|
| 상태 | 완료 |
| 작성일 | 2026-11-18 |
| 질문 | (1) `calendar_info.is_holiday/holiday_name`을 2026~2027년분 채울 공식·실용 데이터원은 무엇이고, 대체·임시공휴일이 언제 반영되는가? (2) `is_school_vacation`을 창원(성산·의창구) 기준으로 어떻게 확보하는가? (3) `is_industrial_vacation`(창원국가산단 하계 집단휴가)을 확인할 공개 자료가 있는가? |
| 관련 작업 | D-DAT-04 (calendar_info 적재), SPEC 5.8, 6.5 |

## 요약

- **공휴일**: Python `holidays` 0.109(2026-11-17 배포)를 기본 데이터원으로 쓰고, 한국천문연구원 특일정보 API(공공데이터포털)로 교차검증하는 방식을 권장한다. `holidays` 0.109는 **2026년 법 개정(노동절 5/1, 제헌절 7/17 공휴일 지정, 둘 다 대체공휴일 적용)**과 2026-06-03 지방선거일을 이미 반영하고 있다. 학교 학사일정(NEIS)의 2026년 공휴일 표기와도 맞다. 다만 **임시공휴일은 지정된 뒤 사후에만 반영되므로** 매년 재생성 절차가 필요하다.
- **2026년 공휴일 변경 주의**: 노동절·제헌절은 2026년부터 공휴일이다(인사혁신처 2026-04-29). 2025년 이전 지식이나 구버전 라이브러리로 만든 달력은 틀린다.
- **학교 방학**: 방학은 학교장이 정하므로 **학교마다 다르다**(창원 6개교 실측: 여름방학 시작 7/22~7/31, 개학 8/12~8/26). NEIS 교육정보 개방포털 `SchoolSchedule` API로 학교별 일자를 받을 수 있다(무료, 인증키는 즉시 발급). 대표 학교 여러 곳의 비율로 `is_school_vacation`을 정하는 방식을 권장한다.
- **산단 휴가**: 공식 통계나 기관 공지는 찾지 못했다. 언론 보도(경남신문 2026-07-28)와 경남경총 조사(뉴시스 2026-07-13)만 있다. 2026년은 **8/3(월)~8/7(금) 1주일**이 주요 대기업 현장직 집단휴가였다. 매년 사람이 설정값으로 넣어야 한다.

### 1. 공휴일 (`is_holiday`, `holiday_name`)

권장 방식:

1. `holidays` 패키지(버전 고정, 예: `holidays==0.109`)로 `holidays.country_holidays("KR", years=[2026, 2027], language="ko")`를 만든다.
2. 결과를 `calendar_info`에 적재한다. 같은 날짜에 공휴일이 여럿이면 `holiday_name`은 `; `로 잇는다.
3. **임시공휴일 보정**: 패키지가 반영하지 못한 임시공휴일은 `config/`의 수동 목록(`date`, `name`, 근거 URL)으로 덧붙인다. 현재 2026년 임시공휴일 근거는 찾지 못했다 → 목록은 비워 두고 `TODO(R-05)` 주석을 단다.

### 2. 학교 방학 (`is_school_vacation`)

- API: `GET https://open.neis.go.kr/hub/SchoolSchedule?KEY=<NEIS_API_KEY>&Type=json&pIndex=1&pSize=1000&ATPT_OFCDC_SC_CODE=S10&SD_SCHUL_CODE=<코드>&AA_FROM_YMD=YYYYMMDD&AA_TO_YMD=YYYYMMDD`
- 방학일 판정: `EVENT_NM`에 `방학`이 들어 있고 `방학식`은 아닌 행 → 그 날짜는 방학. (`SBTR_DD_SC_NM="휴업일"`과 함께 나타남.) "학년말 방학", "봄방학" 같은 표기도 있을 수 있으므로 정규식은 설정값으로 둔다.
- 대표 학교(후보, 성산·의창구, 출근 경로 주변 여부는 R-03 결과와 맞춰 재선정):
  - 초: 용호초 `9022077`, 사파초 `9022048`, 반송초 `9022041`, 명서초 `9022038`, 도계초 `9022031`
  - 중: 창원중앙중 `9022170`, 팔룡중 `9022173`
  - 고: 창원중앙고 `9010071`, 창원중앙여고 `9010072`, 창원남고 `9010115`
- 집계 규칙(제안): 날짜별 "대표 학교 중 방학인 학교 비율"을 계산하고, 50% 이상이면 `is_school_vacation=1`. 비율 자체도 보관하는 것을 권장(SPEC 변경 제안 참고).
- 갱신 주기: 학년도별로 3월 초에 한 번, 이후 월 1회 재조회(학교가 일정을 바꿀 수 있음, `LOAD_DTM`으로 변경 확인).
- 2027년 3월 이후 값은 2027학년도 일정이 등록된 뒤에만 채울 수 있다. 그전까지는 NULL 또는 `0` + "미확정" 플래그로 둔다(불변식 2: 모르는 값을 0으로 확정하지 않음).

### 3. 산단 휴가 (`is_industrial_vacation`)

- 공개 데이터원이 없으므로 `config/`에 연도별 수동 설정값으로 관리한다. 각 항목에 근거 URL을 적는다.
- 2026년 값(근거 E2, E3):
  - `2026-08-03` ~ `2026-08-07`: 주요 대기업 현장직 집단휴가 주간 → `1`
  - `2026-07-27` ~ `2026-07-31`: 일부 기업만 휴가(한화 계열 등) → 이진값으로는 `0`. 필요하면 "부분" 단계를 두는 것을 검토
- 2027년 값: 미정. `TODO(R-05)` — 2027년 7월 중하순 언론 보도·경남경총 조사 발표 후 사람이 입력.

## 미확인·사람 확인 필요

1. **특일정보 API 인증키 발급과 시험 호출**(공공데이터포털 활용신청): `solYear=2026`, `solMonth=05`와 `07`에서 노동절·제헌절이 `isHoliday=Y`로 나오는지, 오퍼레이션 이름(`getRestDeInfo` 등)과 JSON 지원 여부를 확인한다. 받은 응답은 키를 지운 뒤 `docs/research/samples/`에 저장해 달라.
2. **NEIS 인증키 발급**(open.neis.go.kr 로그인 → 인증키 신청, 즉시 발급): 키 이름(예: `NEIS_API_KEY`)을 `.env.example`에 추가해 달라. 전체 조회(5행 제한 없음) 샘플 1건을 저장해 달라.
3. 경남교육청 "2026학년도 학사일정 현황" 첨부파일(초·중·고) 형식을 열어보고 학교별 방학일이 있는지 확인. 있으면 NEIS의 대안 또는 검증 자료로 쓸 수 있다.
4. 대표 학교 선정 기준 결정: 출근 경로(R-03) 주변 학교로 할지, 성산·의창구 전체로 할지.
5. 2026~2027년 임시공휴일: 이 조사 시점(2026-11-18)까지 2026년 임시공휴일 지정 근거는 찾지 못했다. 웹 검색 도구가 작동하지 않아 조사 범위가 제한적이었으므로, 인사혁신처 보도자료 목록에서 2026년 임시공휴일 지정 여부를 한 번 더 확인해 달라.
6. 산단 휴가: 2027년 이후 매년 7월에 입력해야 한다(운영 절차로 등록 필요).
