| 항목 | 내용 |
|---|---|
| 상태 | 완료 (공개 문서 범위. 실제 호출 확인은 사람 작업으로 남음) |
| 작성일 | 2026-11-18 |
| 질문 | 공공데이터포털 「경찰청_교통소통정보 서비스」(15087120)로 창원대로 링크별 속도를 5분 단위로 기계 수집할 수 있는가? 가능하다면 호출 URL, 파라미터, 응답 필드, 단위, 결측 표현, 갱신 주기, 호출 제한은 무엇인가? |

## 요약

- **이 서비스는 링크별 속도 XML API가 아니다(공식 문서 기준).** 공공데이터포털 항목은 `제공형태: LINK`로, 실제 내용은 UTIC 「교통소통정보 레퍼런스」 페이지로 연결된다. UTIC는 이 데이터를 **"지도기반 전국 실시간 교통소통정보", 제공방식 "URL(키값, ip 인증)"**로 안내한다. 같은 페이지에서 돌발정보는 "URL, XML"로 구분해 표기하고 필드 정의·샘플 URL을 공개하지만, 소통정보에는 필드 정의·샘플 URL·XML 예제가 **전혀 없다.** 포털 메타데이터의 `endpointURL`도 비어 있다.
- 포털은 데이터 형식을 "XML"로 적어 두었지만 UTIC 원문과 맞지 않는다. 원문 쪽이 더 구체적이므로 **"키를 넣은 URL로 지도 화면을 띄워 주는(임베드) 서비스"일 가능성이 높다**(추론, 확신도 중간~높음).
- UTIC는 **"교통량 데이터는 제공하지 않음"**이라고 명시한다(사실).
- 결론: 링크 ID·속도·통행시간 필드명, 단위, 결측 표현, 갱신 주기, 호출 제한은 **공개 문서로 확인할 수 없다.** 키를 발급받아 사람이 실제로 호출해 봐야 한다. 그때까지 C-02와 D-COL-01은 이 서비스를 주 수집원으로 고정하지 말고, **ITS 국가교통정보센터 소통정보 API(R-02)를 주 수집원 후보로 우선 검토**할 것을 권한다.
- UTIC 웹 지도(`/map/map.do`)와 모바일 텍스트 화면(`m.utic.go.kr/text/roadList.do`)에 속도가 보이지만, 이것은 웹 화면이다. 불변식 8에 따라 이용약관 확인과 사람의 승인 없이 수집에 쓰지 않는다.

## 미확인·사람 확인 필요

사람(키 관리자)이 해야 할 일. 이 리서치 에이전트는 키를 다루거나 실제 호출을 하지 않았다.

1. **키 발급 경로 확인**: 공공데이터포털 15087120 활용신청(자동승인)만으로 키가 나오는지, UTIC 「개방데이터 신청」(https://www.utic.go.kr/guide/newUtisDataWrite.do)에서 "소통정보 데이터"를 따로 신청해야 하는지 확인. 신청 IP는 수집 PC의 공인 IP. 유동 IP라면 문제가 될 수 있다.
2. **키와 함께 안내받는 "URL"의 실체 확인 (가장 중요)**: 발급 메일이나 안내에 적힌 소통정보 URL을 열어
   - 응답이 HTML 지도 페이지인지, 링크 단위 XML/JSON 데이터인지 확인
   - 데이터라면 루트 요소, 링크 ID·속도·통행시간·등급·시각 필드명, 단위, 결측 표현(빈 값, 0, -1, "정보없음" 코드)을 확인
   - 응답 1건을 키·IP를 지운 뒤 `docs/research/samples/utic_traffic_<YYYYMMDD>.xml`로 저장
3. **영역 필터 여부**: 응답이 데이터라면 좌표 범위·지역·도로 필터 파라미터가 있는지, 없으면 전국 응답 크기(MB)가 얼마인지 확인
4. **갱신 주기 실측**: 1분 간격으로 10~15회 호출해 기준 시각 값이 바뀌는 간격을 기록
5. **호출 제한 문의**: 경찰청 교통안전과(포털 표기 02-3150-0615) 또는 UTIC(02-3495-2087)에 소통정보 일일 호출 한도, 운영단계 심의 요건, 표준노드링크 버전을 문의
6. **웹 화면 수집 여부 판단**: 소통정보가 지도 화면으로만 제공된다면, 웹 화면(`/map/map.do`, `m.utic.go.kr/text/...`) 수집은 이용약관 확인과 사람의 승인 전에는 하지 않는다(불변식 8). 진행 여부는 사람이 결정한다.
